# 凌风的书架 · 风起之地

一个纯静态的轻小说在线阅读器。无框架、无构建依赖，双击 `index.html` 就能读。

## 功能

**书架**
- 卡片视图 / 封面墙视图双模式
- Bento 布局：继续阅读 + 书房状态
- 搜索书名、筛选（在读 / 未读 / 读完）、排序（顺序 / 进度 / 字数 / 最近）
- 多卷系列用叠放书脊表现，点击弹出封面平铺选卷

**阅读**
- 上下滚动（无翻页模式）
- 6 套主题：和纸 / 蕾姆蓝 / 雨雾 / 王冠 / 蓝染 / 夜 / 墨
- 霞鹜文楷 / 小赖字体切换，字号行距版心可调
- 目录 / 人物 / 书签 / 插图 四个侧栏 Tab
- 每章独立地址（`#/书id/章节id`），支持前进后退

**插图**
- 插图页自动识别 → 画廊视图（2 列，横图自动跨列）
- 连贯灯箱：← → 翻页、缩略图胶片条、下载原图、定位原文
- 侧栏「插图」Tab 汇总全卷插画

## 本地预览

因为用了相对路径加载图片，需要用 HTTP 服务打开（直接 `file://` 打开图片会裂）：

```bash
# 任选其一
npx serve site
python -m http.server 8000 --directory site
```

然后访问 `http://localhost:8000`。

## 部署到 GitHub Pages

1. 新建仓库（Public）
2. 把 `site/` 里的**全部内容**推到仓库根目录
3. Settings → Pages → Source 选 `Deploy from a branch` → `main` / `(root)`
4. 等一分钟，访问 `https://<用户名>.github.io/<仓库名>/`
